# 🚀 InterviewAI Pro

An AI-powered interview preparation platform built using React, FastAPI, Firebase, and Groq AI.

InterviewAI Pro helps users upload resumes, generate AI interview questions, practice live interviews with voice interaction, analyze performance, and download interview reports.

---

# 🌟 Features

## 🤖 AI Resume Analysis
- Upload PDF resumes
- AI-generated interview questions
- Personalized interview preparation

## 🎤 Voice Interview Mode
- Speech-to-text support
- AI voice responses
- Real-time AI interviewer interaction

## 📷 Webcam & Emotion Detection
- Live webcam integration
- AI confidence/emotion detection

## 📊 AI Performance Dashboard
- Confidence score
- Communication score
- Technical knowledge score

## 📝 Interview Report PDF
- Download AI-generated interview reports
- Includes scores and AI feedback

## 🔐 Authentication System
- Firebase Login / Signup
- Secure user authentication

## ☁️ Cloud Database
- Firestore database integration
- Save interview history
- Store reports and scores
